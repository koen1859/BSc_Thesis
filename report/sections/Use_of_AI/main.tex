\section{Use of AI}
I made use of AI-based tools during the course of this research, primarily ChatGPT, but also sometimes GitHub Copilot or DeepSeek R1.
These tools were used for the following purposes:
\begin{itemize}
	\item At the start of the project, I used these tools to help come up with ideas and approaches.
	      Most of the suggestions were either incorrect or inefficient.
	      However, this can still be useful since this makes you think critically about the problems at hand.
	      Understanding exactly what is wrong or inefficient about the idea an AI tool generated, can help come up with a better idea.
	\item For code-related tasks, I used these tools to assist with writing syntax I find annoying to write myself, such as making plots.
	      I noticed during the project that AI is not useful for writing key parts of the programs, the code it generates is almost always wrong.
	      A text editor with a good LSP (Language Server Protocol) (like \url{pyright} for \url{Python}) is much more useful in providing auto-completion and error-checking features for programming, compared to AI tools.
	\item For writing and editing text, these tools were occasionally used to help rephrase sections of this report, particularly to improve clarity or flow.
\end{itemize}
